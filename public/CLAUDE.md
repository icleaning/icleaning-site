# iCleaning — сайт клининговой компании

Это корневая папка нового сайта icleaning.com.ua. Файл описывает контекст проекта для Claude Code.

## Что это за проект

- Пересборка старого сайта клининговой компании (был на WordPress 6.4.8, тема `skillful-wp`).
- Новый сайт — **статический, без CMS**. Единственный серверный файл — `send.php` (отправка заявок с форм).
- Внешние обращения допускаются только к Google Fonts и Web3Forms (`api.web3forms.com`). Это закреплено политикой CSP в `build.mjs` (константа `CSP`): новый внешний сервис (аналитика, карта, виджет) нужно добавить туда, иначе браузер его заблокирует.
- Владелец работает на Windows, Node.js установлен, сайт запускается и проверяется локально.

## Структура и содержание

- Многостраничный сайт (как старый, не одностраничник): главная + раздел услуг:
  - генеральная уборка
  - регулярная уборка (на этой странице — калькулятор стоимости со старого сайта)
  - уборка после ремонта
  - химчистка
  - мойка окон
- Языки: **украинский — основной**, плюс русский, английский и испанский версии; на всех страницах — переключатель языков.
- Контактная почта компании: iclean.information@gmail.com.

## Хостинг

- Старый хостинг закрыт (не оплачен), старый сайт офлайн. Сайты-«соседи» a-cleaning.com.ua и vestalux.com.ua тоже офлайн и, скорее всего, не вернутся.

## Безопасность — обязательно

Старый сайт был заражён (загрузчики «EtherHiding» через смарт-контракт BNB Smart Chain, SEO-спам с бэкдором, поддельные плагины, вредоносный mu-plugin). Поэтому:

1. **Никогда не переносить в проект PHP/JS-код, плагины, темы или mu-plugins из бэкапа старого сайта** (`admin-1_full-2026-06-06_tar.gz`). Из старого сайта допустимы только проверенные изображения, иконочные шрифты и тексты.
2. В коде не должно быть: `eval`, `atob`, `web3`, `ethers`, `pako`, `String.fromCharCode` для сборки кода, `document.write`, обращений к блокчейн-узлам. После крупных правок — проверять сборку поиском по этим словам.
3. Индикаторы компрометации (их появление в проекте = тревога):
   - контракт `0x9179dda8B285040Bf381AABb8a1f4a1b8c37Ed53`
   - хосты `cdn.ethers.io`, `bsc-dataseed.binance.org`, `bsc-dataseed1.binance.org`, `bsc-testnet-rpc.publicnode.com`
   - каталоги `hseo`, `wp-backend-monitor`, `google-rank-booster`, `seo-optimizer-pro`, `easy-themes-manager`, `skillful-wp-Theme111`, файл `dev-ci-lint-woocommerce-job-update.php`
4. Не хранить в проекте пароли, ключи и сертификаты (старые ключи Let's Encrypt из бэкапа считаются скомпрометированными). Репозиторий **публичный**: всё, что в него попало, видно всем, включая историю коммитов.
5. Не добавлять inline-скрипты (`<script>` с кодом, `onclick=`) и `innerHTML` с текстом из контента — CSP их блокирует. JSON-LD выводить через `ldJSON()`.
6. GitHub Actions в `.github/workflows/pages.yml` закреплены по SHA коммита; обновления предлагает Dependabot. Сборка падает, если в `dist/` найдены индикаторы вредоноса или PHP-файлы.
7. Ловушка для ботов в форме — скрытый чекбокс `botcheck` (его понимают и Web3Forms, и `send.php`).

Полный отчёт о заражении — в проекте claude.ai «iCleaning», документ `claude/malware-report.md`.

## Выкладка и GitHub

- С ноября 2026 сайт размещается на **GitHub Pages** (бесплатно). Пробный период CityHost закончился. Скрипт FTP-выкладки `deploy-ftp.ps1` удалён из репозитория (аудит 22.11.2026): в публичном репо он раскрывал FTP-хост и логин.

- Домен icleaning.com.ua — файл `public/CNAME`. Регистратор домена — imena.ua (оплачен до 26.12.2026). DNS: A-записи на 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153 и CNAME `www` → `icleaning.github.io`.
- PHP на Pages нет, поэтому `send.php` не работает. Заявки с форм уходят через Web3Forms: ключ доступа в `src/config.json` → `site.formAccessKey` (ключ не секретный, его можно хранить в коде). Если ключ пустой, формы шлют на `/send.php`.
