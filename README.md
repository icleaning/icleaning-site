# iCleaning — сайт клининговой компании (uk · ru · en · es)

Обновлённая версия сайта icleaning.com.ua. Вместо WordPress (тема 2015 года, WPBakery, Revolution Slider и ~35 плагинов, часть из которых была заражена) — **чистый статический сайт: HTML + CSS + JavaScript**. Он выглядит как оригинал, но не содержит ни одной строки старого кода, работает без базы данных и админки, открывается мгновенно и почти не может быть взломан.

* **Языки:** украинский (основной, без префикса в адресе), русский `/ru/`, английский `/en/`, испанский `/es/`, переключатель в шапке.
* **Адреса страниц** украинской и русской версий **совпадают со старыми** (так задавал Polylang), поэтому поисковый трафик и закладки не потеряются.
* **Страницы:** главная со слайдером; услуги (генеральная, регулярная, эко, после ремонта, химчистка, мойка окон); FAQ; инфоцентр и 5 статей; «спасибо за заявку»; 404.
* **Калькуляторы:** регулярная уборка (комнаты + допуслуги + частота, первая уборка +50 %) и калькулятор по площади (генеральная и эко-уборка) — цены актуальные, из базы данных бэкапа.
* **Заявки:** окно «Оформить замовлення» + `send.php` (отправка на e-mail).

> Про вредоносный код в старом сайте — см. [`docs/MALWARE-REPORT.md`](docs/MALWARE-REPORT.md). **Прочитайте его до размещения на хостинге** (нужно сменить пароли).

## 1. Запуск на своём компьютере

Нужен [Node.js](https://nodejs.org) версии 18 или новее (никаких пакетов устанавливать не нужно).

```bash
cd icleaning-site
npm run dev          # или: node build.mjs --serve
```

Откройте http://localhost:4321/ . Сервер сам пересобирает сайт при каждом сохранении файла в `src/` или `public/` — достаточно обновить страницу в браузере.

Без Node.js: в папке `dist/` лежит готовая собранная версия. Её нужно открывать через любой веб-сервер (двойной клик по `index.html` не подойдёт — адреса в ней начинаются с `/`), например:

```bash
python3 -m http.server 4321 -d dist
```

Отправка заявок на локальном компьютере **не работает** (нет PHP) — форма показывает тестовое сообщение. На хостинге с PHP заявка уходит на почту.

## 2. Из чего состоит проект

```
build.mjs               генератор сайта (Node.js, без зависимостей)
src/config.json         телефон, Facebook, адреса (slug) страниц, цены калькуляторов
src/content/uk.json     тексты украинской версии  ┐
src/content/ru.json     русской                    │ всё, что видит посетитель:
src/content/en.json     английской                 │ меню, страницы, FAQ, статьи, отзывы,
src/content/es.json     испанской                  ┘ подписи калькуляторов, футер
public/                 копируется в dist как есть:
  css/style.css           весь дизайн (цвета и шрифты — переменные в начале файла)
  js/site.js              слайдер, отзывы, форма, калькуляторы, меню
  img/                    логотип, фото слайдера, фото статей, иконки
  fonts/                  иконочные шрифты оригинала
  send.php                обработчик заявок
  .htaccess               настройки для Apache
dist/                   ГОТОВЫЙ САЙТ — его и нужно загружать на хостинг
docs/MALWARE-REPORT.md  отчёт о вредоносном коде
```

После любой правки выполните `npm run build` (или работайте через `npm run dev`) — `dist/` обновится.

## 3. Как вносить правки

| Что изменить | Где |
|---|---|
| Телефон, ссылка на Facebook | `src/config.json` → `site` (телефон в тексте отзывов/статей — в `src/content/*.json`) |
| Цены калькулятора регулярной уборки, надбавки за частоту, ставка за м² | `src/config.json` → `calc` |
| Цены и тексты на страницах услуг | `src/content/<язык>.json` → `pages.<услуга>.sections` |
| Меню, подписи кнопок, футер, отзывы | `src/content/<язык>.json` → `ui` |
| Заголовки и описания для поисковиков | `src/content/<язык>.json` → `pages.<услуга>.meta`, `home.meta`, `posts.<статья>.seo/desc` |
| Адрес страницы (URL) | `src/config.json` → `slugs` / `postSlugs` |
| Фото слайдера и шапок страниц | `public/img/hero/` (1920×620 px), привязка: `ui.home.slides[].img`, `pages.<услуга>.hero` |
| Цвета, шрифты, размеры | `public/css/style.css` (переменные `:root` вверху) |

Блок `sections` на странице услуги — это список: `{"t":"h","x":"Заголовок"}`, `{"t":"p","x":"Абзац"}`, `{"t":"ul","x":["пункт","пункт"]}` и служебные `{"t":"calc"}`, `{"t":"areacalc"}`, `{"t":"cta"}` (калькуляторы и кнопка). Блоки можно добавлять, удалять и менять местами. HTML-теги в текстах не нужны и не поддерживаются.

**Новая статья:** добавьте её в `src/config.json` (`postSlugs`, `postOrder`, `postImages`), положите фото 1170×580 в `public/img/posts/` и добавьте статью в `posts` каждого языкового файла.

**Новый язык (например, польский):**
1. Скопируйте `src/content/en.json` в `src/content/pl.json` и переведите значения (ключи не трогать); в начале файла поменяйте `lang`, `htmlLang`, `label`, `name`, `locale`.
2. В `src/config.json` добавьте `"pl"` в `langs` и адреса для `pl` в каждую запись `slugs` и `postSlugs`.
3. `npm run build` — язык появится в переключателе и в `sitemap.xml`.

## 4. Размещение на хостинге

Сайт статический, поэтому подойдёт любой хостинг (в том числе самый дешёвый), а также Netlify, Cloudflare Pages, GitHub Pages и т. п.

1. Выполните `npm run build` и **загрузите содержимое папки `dist/`** (не саму папку) в корень сайта (`public_html`, `www`…). Скрытый файл `.htaccess` тоже нужно загрузить.
2. Откройте `send.php` и впишите свои адреса в `$TO` (куда приходят заявки) и `$FROM` (отправитель — лучше адрес на вашем домене, иначе письма попадают в спам). Сейчас в `$TO` стоит адрес администратора старого сайта из бэкапа.
3. Включите HTTPS (бесплатный сертификат Let's Encrypt есть почти у каждого хостера).
4. Если сайт лежит не в корне домена, а в подпапке — укажите её в `src/config.json` → `site.basePath` (например `"/iclean"`) и пересоберите.
5. Домен/адрес для `sitemap.xml`, canonical и hreflang задаётся в `site.domain` (сейчас `https://icleaning.com.ua`).
6. Проверьте после загрузки: главную, переключение языков, калькулятор, отправку тестовой заявки. Затем отправьте `https://ваш-домен/sitemap.xml` в Google Search Console.

Нет PHP? Укажите в `site.formEndpoint` адрес любого сервиса приёма форм (Formspree, Web3Forms и т. п.) и пересоберите.

**Шрифты.** Open Sans, Raleway, Roboto и Libre Baskerville подключаются с Google Fonts (как и на старом сайте). Если нужна полная независимость от внешних сервисов, скачайте их, положите в `public/fonts/` и замените ссылку в `build.mjs` на `@font-face` в `style.css`.

**Аналитика.** Старый код Google Analytics (`UA-64279552-1`) не переносился: Universal Analytics отключён Google. Подключите GA4 или другой счётчик, добавив его код в `renderLayout()` в `build.mjs` (перед `</head>`).

## 5. Что важно знать о содержимом

Тексты и цены взяты из базы данных бэкапа (украинская и русская версии — оригинал; английская и испанская — мой перевод, стоит показать носителю). Я намеренно ничего не «исправлял» в смысле цен, но нашёл несоответствия в самом оригинале — решите, что верно:

* Регулярная уборка: в тексте «от 600 грн», а в калькуляторе минимум 900 грн (1 комната).
* Второй санузел: 500 грн (генеральная, эко), 350 грн (регулярная, допуслуга), «+250 грн» внутри списка регулярной уборки.
* Мойка окон: 100 грн/м² (большинство страниц) и 150 грн/м² (страница регулярной уборки); химчистка: от 75 грн/м² и 150 грн/м².
* «Замена постельного белья» в калькуляторе: 75 грн в украинской версии и 50 грн в русской (в сайте взято 75).
* Телефоны `(044) 353-09-70` в старых статьях заменены на актуальный `(067) 327-34-32`.
* **FAQ** в оригинале был пустой. Я составил ответы только из фактов, уже опубликованных на сайте (цены, режим работы, гарантия) — проверьте их.
* Исправлены явные ошибки машинного перевода в украинских текстах («розлучення на паркеті» → «розводи», «суперечки плісняви» → «спори плісняви» и т. п.) и опечатки.
* В старом калькуляторе по площади «время уборки ~75 часов» показывало ставку 75 грн вместо времени — я это поле убрал.
* Страницы-черновики оригинала (ген. уборка_калькулятор, послестрой, уборка офисов, test…) не переносились — они не были опубликованы.

## 6. SEO и безопасность

* У каждой страницы свои `<title>`, description, canonical, `hreflang` для всех 4 языков, Open Graph; есть `sitemap.xml`, `robots.txt`, разметка schema.org (организация, FAQ, статьи).
* Заголовки и описания страниц взяты из настроек Yoast SEO старого сайта (там, где их не было, — составлены по содержимому страницы).
* Нет CMS, базы данных, плагинов и админки. Единственный серверный код — `send.php` (проверка полей, защита от инъекций в заголовки письма, «ловушка» для ботов); на GitHub Pages он не публикуется, заявки идут через Web3Forms.
* В каждой странице есть политика безопасности контента (CSP, тег `<meta http-equiv="Content-Security-Policy">`): браузер выполняет только скрипты с самого сайта и обращается только к Google Fonts и Web3Forms. Новый внешний сервис нужно добавить в константу `CSP` в `build.mjs`.
* Сборка на GitHub проверяет `dist/` на признаки вредоносного кода старого сайта и на PHP-файлы.
